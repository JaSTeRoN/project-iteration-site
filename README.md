# Сайт курса «Итерация-8»

Статические страницы без Jekyll. Разделы: расписание, проекты и команды, учебные материалы, интерактивные приложения. Готовы плитки Вана (`wang.html`) и подземелье Rogue (`rogue.html`).

Локальный просмотр из папки репозитория:

```powershell
py -3 -m http.server 8765
```

Затем откройте http://127.0.0.1:8765/ . Остановка — Ctrl+C.

## Расписание

`data/schedule.json` хранит зоны, общую ссылку и список занятий. Занятие задаётся один раз — датой и временем по основной зоне (`"primary": "tomsk"`); вторая зона пересчитывается по IANA-таймзоне, а офлайн-занятие в ней показывается как стрим. Недели отдельно не хранятся: они собираются из дат занятий.

`"defaultLink"` — ссылка на видеоконференцию, которая подставляется во все карточки; у занятия можно задать свою `"link"`. Поле `"zones": ["tomsk"]` ограничивает показ одной зоной (так сделано для томского слота в 12:00).

`schedule.html` показывает одну таблицу с переключателем «Томск / Калининград» и меткой «Архив» у прошедших недель. Редактируется в админке.

## Админка

`admin.html` — единая админка: расписание, проекты, материалы, доступ. Вход — fine-grained токен GitHub с правом Contents: Read and write на этот репозиторий. Токен хранится в `localStorage` 12 часов и переиспользуется всеми вкладками админки; старый `schedule-edit.html` перенаправляет сюда.

Права определяет GitHub, а не сайт: коммит проходит только у аккаунта с write-доступом к репозиторию, остальным API отвечает 403. Админка лишь показывает ваши права, которые отдаёт `GET /repos/{owner}/{repo}` (`permissions`).

Данные: `data/schedule.json`, `data/projects.json`, `data/materials.json`, `data/access.json`; загруженные файлы материалов лежат в `materials/`.

## Доступ к приложениям

Мягкое ограничение: `data/access.json` хранит правила вида `{ "target": "wang.html", "open": "2026-11-05T17:00", "zone": "Asia/Tomsk" }`. До этого момента карточка на `apps.html` закрыта, а страница приложения показывает заглушку (`assets/js/access.js`). Это не защита: файлы остаются в открытом репозитории и доступны по прямой ссылке.

## Картинки

Страницы используют WebP из `assets/brand/`. Исходные PNG после сжатия сложены в `assets/brand/_originals/` и в репозиторий не попадают (см. `.gitignore`).
