# Сайт курса «Итерация-8» в рамках программы "ГПО для школьников"




## Расписание

`data/schedule.json` хранит зоны, общую ссылку и список занятий. Занятие задается один раз - датой и временем по основной зоне (`"primary": "tomsk"`); вторая зона (на данный момент Калининград) пересчитывается по IANA-таймзоне, а оффлайн-занятие в ней показывается как стрим очного занятия. Недели отдельно не хранятся: они собираются из дат занятий.

`"defaultLink"` - стандартная ссылка на видеоконференцию, которая подставляется во все карточки по умолчанию; у любого занятия можно задать свою `"link"`. Поле `"zones": ` позволяет ограничить показ одной зоной.

`schedule.html` показывает одну таблицу с переключателем "Томск / Калининград" и меткой "Архив" у прошедших недель. Редактируется в админке.

## Админка

`admin.html` - единая админка: расписание, проекты, материалы, доступ. Вход по fine-grained токену GitHub с правом _Contents: Read and write_ на этот репозиторий. Токен хранится в `localStorage` 12 часов и переиспользуется всеми вкладками админки.

Все изменения на уровне админки вносятся коммитом; коммит проходит только у аккаунта с write-доступом к репозиторию, остальным API отвечает 403. Админка по сути лишь показывает Ваши права, которые отдает `GET /repos/{owner}/{repo}` (`permissions`).

Данные: `data/schedule.json`, `data/projects.json`, `data/materials.json`, `data/access.json`; загруженные файлы материалов лежат в `materials/`.

## Доступ к приложениям

Мягкое ограничение: `data/access.json` хранит правила вида `{ "target": "wang.html", "open": "2026-11-05T17:00", "zone": "Asia/Tomsk" }`. До этого момента карточка на `apps.html` закрыта, а страница приложения показывает заглушку (`assets/js/access.js`). Так или иначе, файлы остаются в открытом репозитории и доступны по прямой ссылке.

## Развернуть локально

Из папки репозитория:

```powershell
py -3 -m http.server 8765
```

Затем открыть http://127.0.0.1:8765/ . Остановка — Ctrl+C.
