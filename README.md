# Сайт курса «Итерация-8»

Статические страницы без Jekyll. Разделы: расписание, проекты и команды, учебные материалы, интерактивные приложения. Готовы плитки Вана (`wang.html`) и подземелье Rogue (`rogue.html`).

Локальный просмотр из папки репозитория:

```powershell
py -3 -m http.server 8765
```

Затем откройте http://127.0.0.1:8765/ . Остановка — Ctrl+C.

## Расписание

`data/schedule.json` хранит зоны и занятия. Занятие задаётся один раз — датой и временем по основной зоне (`"primary": "tomsk"`); вторая зона пересчитывается по IANA-таймзоне, а офлайн-занятие в ней показывается как стрим. Недели отдельно не хранятся: они собираются из дат занятий плюс текущая неделя. Поле `"zones": ["tomsk"]` у занятия ограничивает показ одной зоной.

`schedule.html` показывает неделю с переключением и меткой «Архив» у прошедших. `schedule-edit.html` — редактор: сохраняет коммитом в `main` через GitHub API, нужен fine-grained токен с правом Contents: Read and write на этот репозиторий.

## Картинки

Страницы используют WebP из `assets/brand/`. Исходные PNG после сжатия сложены в `assets/brand/_originals/` и в репозиторий не попадают (см. `.gitignore`).
