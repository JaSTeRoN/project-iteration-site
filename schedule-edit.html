Правка расписания

Токен нужен только вам. Создайте на GitHub fine-grained token с правом Contents: Read and write только для репозитория project-iteration-site. Он останется в этой вкладке и в файлы сайта не попадёт. Сохранение делает коммит прямо в main — сайт обновится через минуту.

Время вводится по Томску, калининградское пересчитывается само.

К расписанию
